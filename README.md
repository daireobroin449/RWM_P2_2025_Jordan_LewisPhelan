
### User Testing Procedure

1.  User is introduced to app - Or in the TeamApp variant directed to add '/planning' to the url ending - No button on the page set-up to redirect naturally.
2. While User is going to the page they are given a few simple points to try achieve gradually:
   2.1. Ask user to find an existing 'Task' and Update it in any way - (For Tester: This can mean they open any of the 6 default Tasks and add a new subtask or check off existing subtasks AND hit Save so it updates).
   2.2 Ask User to Make a new custom shape and name it or give it a custom description - (For Tester: Can be any shape - goal is to perceive how they react to this ask and if they can find and make one without help).
   2.3 Ask user to make another shape, but this time after making this new one connect this shape to the other shape or a task using the Arrow Tool - (For Tester: Goal is to check if they have any difficulty or are unsure of what they are doing - check for uncertainty). 
   2.4 Ask them to mark the Arrow as an 'Old Idea' OR Edit the Shapes they made - (For Tester: See if the user struggles with this or if they are unsure how to do it. May have instinct/awareness to double click on the Elements).
   2.5 Ask them to delete an Element from the Canvas.


### User Test Feedback

1. First Tester: Had some issues Figuring out how to interact with the shapes and arrows after placing them <- (This was actually bugged for this test and could not be opened). Had some confusion about connecting Elements.
   
   Changes from 1. - Added the Shapes/Arrow Controls to the bottom of the page with the other controls to ensure User has some direction. Added Arrow Tool update where the Tool button changes colour and text displayed explains what to do - click 2 different shapes/elements. Fixed the bugged Shape interaction - not opening modals.

2. Second Tester: Had some issues deleting Tasks from the Canvas - Shapes and arrows were deleting but the Tasks refused to - User tried desperately to delete the Tasks, even after being told that was not an intended feature currently and previously deleting several shapes.
   
   Changes from 2. - I had to add the stipulation that Users were not meant to delete the Tasks as those were meant to be more for fulfilment and deleted elsewhere in a full scale product - connected to Task Board.
